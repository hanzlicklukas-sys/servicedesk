# Lukas ServiceDesk

Mobile Geschäftsverwaltung für Gartenservice und Technikhilfe.

## Aktueller Funktionsumfang

- Dashboard mit Kunden, Aufträgen und Einnahmen
- Kundenkartei mit Telefonkontakt und Notizen
- Auftragserfassung mit Termin, Preis und Status
- Statusfolge von Anfrage bis bezahlt
- Responsive Oberfläche für Smartphone und Desktop
- Lokale Speicherung im Browser

## Entwicklung

```bash
npm install
npm run dev
```

Danach ist die App unter [http://localhost:3000](http://localhost:3000) erreichbar.

## Nächste Ausbaustufe

Die lokale Speicherung wird durch Supabase ersetzt. Damit stehen Login, zentrale
Cloud-Speicherung und synchronisierte Daten auf Smartphone und Computer zur
Verfügung.
